# DNS Checker

Desktop tool checks which public DNS servers will help an Xbox owner who can't sign in to Xbox Live (error 0x80a40401 and similar). Python + CustomTkinter, Windows.

Программа показывает, какие DNS-серверы помогут абоненту, у которого Xbox не входит в Xbox Live. Консоль для этого не нужна.

## Что умеет

**Вкладка «Xbox»**
- для каждого DNS проверяет домены Xbox Live так же, как это делает консоль:
  резолв → TCP → TLS с SNI и проверкой сертификата → HTTP-запрос;
- отличает «адрес ведёт напрямую в Microsoft» (с российского IP будет блок по региону)
  от «адрес ведёт на шлюз, который отвечает от имени Microsoft» (обход работает);
- узнаёт владельца IP через RDAP и показывает, кто на самом деле отвечает на запросы DNS
  (`whoami.akamai.net`) — так виден перехват запросов к 8.8.8.8 и другим публичным DNS;
- итог по каждому DNS: «Поможет / Под вопросом / Не поможет / Не отвечает»;
- кнопка «Ответ абоненту» — готовый текст с инструкцией и подходящей парой DNS; (создан для собственного удобства в работе)
- наблюдение в фоне: проверка каждые N минут и уведомление, если DNS перестал (или снова начал) помогать;
- история проверок в `xbox_log.csv`: когда, какой DNS, итог и какие проверки не прошли — видно,
  с какого дня DNS перестал помогать.

**Вкладка «Серверы»**
- быстрая проверка, живы ли DNS-серверы, с автоповтором;
- лог в CSV (открывается в Excel).

Список серверов общий для обеих вкладок: строки можно перетаскивать, переименовывать двойным
кликом, сортировать.

## Запуск из исходников

Нужен Python 3.14 (на нём собран .exe; на 3.10+ тоже должно работать).

```bash
pip install -r requirements.txt
python dns_checker_gui.py
```

## Сборка .exe

```bat
build.bat
```

Готовая программа появится в `dist\DNS-Checker\`.

## Файлы рядом с программой

При первом запуске программа создаёт рядом с собой:

| Файл | Что внутри |
|---|---|
| `servers.txt` | список DNS-серверов (адрес и название) |
| `consoles.json` | домены Xbox, которые проверяются |
| `reply_template.txt` | шаблон ответа абоненту (`{dns1}`, `{dns2}`) |
| `settings.json` | настройки окна и вкладок |
| `ip_owners.json` | кэш владельцев IP на 7 дней |
| `dns_log.csv` | лог вкладки «Серверы» |
| `xbox_log.csv` | история проверок вкладки «Xbox» |

## Структура проекта

```
dns_checker_gui.py        точка входа
dnschecker/
  config.py               значения по умолчанию: серверы, домены Xbox, шаблон ответа
  paths.py                где лежат файлы программы
  storage.py              чтение и запись файлов
  dns_tools.py            DNS-запросы и проверка «кто отвечает»
  http_probe.py           подключение TCP → TLS → HTTP, как у консоли
  owners.py               владелец IP через RDAP (с кэшем)
  xbox.py                 проверка доменов Xbox и итоговый вердикт
  server_list.py          общий список серверов и сортировка
  reply.py                текст ответа абоненту
  ui/                     интерфейс (CustomTkinter)
tests/                    тесты логики: python -m pytest
```
