По провайдерам

Комбинация «DNS + провайдер» публикуется только с тремя и более отчётами.

Что здесь нельзя увидеть — намеренно

  • Нет имён, IP абонентов, текста обращений — схема отчёта их не собирает.
  • Группы с меньше чем тремя отчётами не показываются вовсе: один звонок нельзя вычислить через статистику.
  • Даты — только на уровне недели или группы, без привязки к отдельным отчётам.
