# История версий DNS Checker

## 5.0 — 2026-11-24 (Platform 2.0)

Не утилита, а диагностическая платформа с обратной связью: каждый звонок
делает следующий быстрее.

- **Веб-проверка** (новое): страница по ссылке сравнивает ответы публичных DNS
  (Google, Cloudflare) с проверенным списком рабочих адресов. Без установки.
  https://igisanoi.github.io/Xbox-DNS-check/
- **Веб-отчёты** (новое): две кнопки на странице — итог с консоли уходит в общую
  таблицу; локальная очередь доправляет при следующем визите.
- **Сводная статистика** (новое): панель из той же таблицы; агрегаты только
  (группы меньше трёх отчётов не показываются никогда).
  https://igisanoi.github.io/Xbox-DNS-check/dashboard.html
- **Рекомендуемые DNS** (новое): панель на вкладке «Xbox» предлагает DNS,
  подтверждённые на консолях («подтверждено: N из M»). Предложение, не
  автонастройка. Работает на устаревшем кэше без сети.
- **IP-обход** (новое): проверка статических записей «домен → IP» тем же
  способом, что подключается консоль (TCP → TLS с SNI → HTTP); результаты с
  меткой времени пишутся в ip_overrides_log.csv.
- **Проверка версии** (новое): при запуске спрашивает GitHub о новом релизе;
  уведомление со ссылкой, без автообновлений.
- Статистика и веб — в отдельном репозитории слоя: приложение работает без
  сети и без облака ровно как 4.x.

## 4.1 — 2026-11-11

- Анонимные отчёты с консоли в общую Google-таблицу (схема 1): итог, место
  настройки, сеть — без имён и IP абонентов. Очередь outbox, дедупликация
  по report_id, серверная валидация.
- Наблюдение в фоне с уведомлением об изменениях итогов.
- История проверок в xbox_log.csv, «кто реально отвечает» через whoami.akamai.net
  с распознаванием перехвата запросов.
- Ответ абоненту по шаблону reply_template.txt.
